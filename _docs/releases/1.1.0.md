# ShiftMate 1.1.0 심사 제출 준비

- 작성일: 2026-11-22 (Asia/Seoul)
- 대상: iOS 1.1.0(8), Bundle ID com.hspark.shiftmate, API 호환 번호2
- 기능 커밋: 1752108 (`origin/develop` 푸시 확인)
- 상태: 서명 빌드 생성·로컬 검증 완료. 업로드·Connect 처리/빌드 선택·최종 심사는 아직 수행하지 않았다.
- 원격 포털은 현재 브라우저 제어 중지로 직접 확인하지 못했다. 로컬 빌드7을 보존하고 다음 번호8을 사용했으며 Connect 중복 여부는 확인 전이다.

## 이번 버전의 변경 사항

- 가입/프로필 입력 및 Firebase 휴대폰 인증 흐름을 개선했다.
- 캘린더는 날짜를 선택하기 전 넓게 표시하고 작은 화면은3주로 보여준다.
- 여러 날 일정은 연결 막대로, 겹치는 일정은 공간에 맞게 여러 줄로 표시한다.
- 다른 달로 이동해도 선택한 일정 카드를 유지하며 아래로 끌어 부드럽게 닫을 수 있다.
- 개인 일정 카드에 시작일·종료일이 다른 경우 날짜 범위를 추가했다.
- 그룹 캘린더의 일정 표시와 제목 가독성을 개선했다.
- 하단 캘린더 탭을 다시 누르면 오늘로 이동한다.
- 오늘/내일 홈·잠금화면 위젯에 개인 일정 유무·건수를 추가했다. 일정 제목/메모/장소는 위젯에 전달하지 않는다.

## App Store ‘새로운 기능’ 입력 초안

```text
캘린더와 일정 확인이 더 편리해졌어요.

• 날짜 선택 전에는 캘린더를 넓게, 작은 화면에서는 3주로 볼 수 있어요.
• 여러 날 이어지는 일정과 같은 날의 여러 일정을 더 쉽게 확인할 수 있어요.
• 달력을 넘겨도 선택한 일정 카드를 유지하고, 아래로 끌어 닫을 수 있어요.
• 개인 일정의 날짜 범위와 그룹 일정 표시를 개선했어요.
• 하단 캘린더 버튼을 다시 누르면 오늘로 돌아와요.
• 홈 화면과 잠금화면 위젯에서 오늘·내일 근무와 일정 유무·건수를 확인할 수 있어요.
• 가입과 프로필 입력, 휴대폰 인증 흐름을 개선했어요.
```

## API 호환 번호2 배포 순서

이번 앱은 호환2다. 2026-11-22 직접 조회한 운영 최소값은1이라 호환1/2를 모두 허용한다. 이 작업에서는 서버 최소값을 바꾸지 않았다. 호환2 앱이 심사 승인되어 App Store에서 실제 제공된 뒤 서버 최소값2 적용을 진행한다. 서버부터2로 바꾸면 기존 호환1 앱은 업데이트 화면으로 차단된다. 선행1.1.0(7)/호환1은 build/ios/releases/1.1.0-7에 보존한 미제출 파일이므로 이번 제출에 사용하지 않는다.

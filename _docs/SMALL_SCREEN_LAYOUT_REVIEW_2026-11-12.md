## 검증 범위

- 새 위젯 회귀:320×568,360×640,375×667,390×844,430×932,667×375,768×1024.375px에서1.1/1.25배,320px에서2/3.2배, 가로에서2배를 포함한다.2배 조건은 다크 테마도 주입한다. 실제 Cafe24/Cupertino 폰트·안전영역·동작 줄이기를 사용한다.
- 날짜/시간의 실제 텍스트 박스·행 정렬/높이·최소48px, 긴 시간11:59/12:59·연도 경계·종일 전환 값 보존, 본문 스크롤 전후 저장 위치, 시간/연월 휠 접근과 전체 연도 텍스트를 확인한다.
- 동작 줄이기에서는 두 연월 휠을2000년1월로 옮긴 뒤 이번 달 버튼으로 실제 두 선택 인덱스와 요약이 즉시 동기화되는지도 확인한다. 마지막 보완 후 작은 화면36개와 기존 연월2개, 총38개가 통과했다.
- 기존 개인 일정/근무 타입·피커/드래그·저장/친구 검색 회귀와 전체 Flutter suite를 실행한다. 친구 목록 실제 API 분기는 GROUP_API_ENABLED=true의 모의 repository로 따로 확인한다.
- 근무 타입은 기존340px/큰 글자의 세로 전환과 공용 시간 피커를 사용한다. 프로필 편집·색상/커스텀 색상은 기존 본문 스크롤·최대폭/배율 대응 및 관련 회귀를 확인했다. 이들 화면의 모든 OS 키보드/실데이터 조합을 새로 시각 검증하지 않았다.
- 메인/친구/그룹 캘린더와 하단 탭은 이번에 배치를 수정하지 않았다. 기존 페이지/내비게이션 회귀로 확인한다. 도면의 구형calendars/calendar_shares와 최신 사용자 단위 스키마 차이는 기존 문서대로 유지한다. 이번 변경은 DB 계약에 영향을 주지 않는다.

## 재현과 산출물

```sh
flutter test --no-pub test/features/calendar/presentation/widgets/compact_layout_test.dart --dart-define=KAKAO_NATIVE_APP_KEY_STAGE=test-stage-key
COMPACT_LAYOUT_RENDER_OUTPUT=artifacts/compact_layout_2026-11-12 flutter test --no-pub test/features/calendar/presentation/widgets/compact_layout_test.dart --dart-define=KAKAO_NATIVE_APP_KEY_STAGE=test-stage-key
flutter test --no-pub --dart-define=KAKAO_NATIVE_APP_KEY_STAGE=test-stage-key
```

- 신규 `compact_layout_test.dart`: Flutter WidgetTester/실제 팝업·intl·번들 폰트를 사용하는 회귀/선택적 PNG 렌더러다. 첫 명령은 파일을 생성하지 않는다.
- 신규 `artifacts/compact_layout_2026-11-12/`: 위 명령으로 생성한 화면 크기별 PNG. `event_`는 폼, `time_`는 시간 피커, `month_`는 연월 피커, `date_`는 날짜 피커다. `_wheel`/`_year`는 본문 스크롤 후 실제 휠에 접근한 상태다. 개인 일정은 날짜·시간을 보기 위해 본문을 스크롤한 상태이며 상단 제목 입력 영역은 화면 밖일 수 있다. 서버/인증 데이터는 사용하지 않는다.
- 신규 공용 `ScrollableCenteredBody`와 `PickerSelectionSummary`의 역할/의존성/사용 예는 PROJECT_CONTEXT의 같은 날짜 절에 기록했다.
- [375px·글자1.25배 수정 결과](../artifacts/compact_layout_2026-11-12/event_phone375_text125.png), [320px 수정 결과](../artifacts/compact_layout_2026-11-12/event_small320.png), [가로·글자2배 연월 휠](../artifacts/compact_layout_2026-11-12/month_landscape_text2_wheel.png), [최대 글자 연도 전체 표시](../artifacts/compact_layout_2026-11-12/month_small_text3_year.png).

최종 검증은 전체436 pass/기존 skip1, 새 회귀/렌더36 pass·PNG84개, 그룹 API 활성화 분기16 pass, 기존 메인 진입/키보드 렌더1 pass/17조건이다. 변경 Dart12개 정적 분석 진단0건·포맷/diff 검사도 통과했다. 키보드 렌더는 기존 personal_event_sheet 렌더러의 PERSONAL_EVENT_RENDER_OUTPUT=/private/tmp/shift_small_screen_form_keyboard 옵션으로 별도 생성했다. 전체 suite의 기존 색상 슬라이더 hit-test 경고2건은 별도이며 새 회귀의 조작 경고는 없다. 실기기 Dynamic Type·VoiceOver·실제 키보드 조작은 별도 인수 대상이다. 이번 레이아웃/회귀/산출물/문서 추가분만 제거하면 롤백하며, 기존 및 동시 진행 미커밋 작업은 보존한다.

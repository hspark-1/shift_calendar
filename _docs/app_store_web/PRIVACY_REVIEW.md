## 최종 공개를 위해 남은 결정

1. 정책 시행일: 운영 적용과 최종 검토가 끝나는 실제 게시일로 지정한다.
2. 로그·백업·문의 메일 정책: 채택한 기간에 맞는 실제 정리 설정 및 복구 후 삭제 요청 재반영 절차를 갖춘다. 법정 접근기록 등 별도 보존 의무를 확인해 일반 접속 로그와 구분한다.
3. 잔여 기기·탈퇴 작업·알림 전송·실패 기록: 항목별 보유 목적·운영 보관 기간·삭제 주기를 확정하고 본문 3항의 확인 문구를 교체한다.
4. 이미지 파기: 탈퇴 시 실제 파일·기존 공개 URL·백업·클라이언트/중간 캐시 정리 범위를 확인하여 4항에 실제 절차를 반영한다.
5. 로그인/검색/공유: 해당 처리 근거·동의 화면과 실제 API의 제공 범위를 대조해 1·5항을 확정한다. 방침 게시만으로 별도 동의가 대체되지 않는다.
6. 외부 서비스·국외 이전: Google/Apple 로그인, FCM/APNs, Gmail에 대해 수신 법인·연락처·국가·항목·목적·시점/방법·보유 기간·이전 근거·거부 방법/영향을 실제 계약·공식 정책으로 확정한다. FCM이 글로벌 인프라인데 홈서버만 보고 ‘국외 이전 없음’으로 적지 않는다.
7. 안전성 조치: HTTPS·권한·인증정보 보호와 운영 백업/접근 통제 등 실제 적용된 내용만 본문에 남긴다.
8. 14세 미만 미허용: 정책과 가입 UX·API 운영 절차 일치 확인. 생년월일을 무조건 추가 수집하라는 요구는 아님.

이후 MD와 HTML을 함께 최종화하고 HTML의 검토 배너·문서 내 확정 대기 표현을 제거한다. 개인정보처리방침을 공개한 뒤 `/privacy`의 200·HTML 응답, 지원 링크, 앱 내 접근과 App Store Connect URL을 확인한다. 현재 문서는 공개 전 검토본이며 심사 제출 완료가 아니다.

### S3 운영자 추가 확인 (2026-10-18)

프로필 이미지 버킷은 아시아 태평양(서울) ap-northeast-2, 복제 없음, CDN 없음으로 확인했다. S3 리전·복제·CDN은 더 이상 미정이 아니다. 과거 표의 확인 요청은 이 기록으로 보완한다. 별도 백업 유무/위치·계약 법인·실제 버전/원본 파기·캐시 결과는 운영 증거 대기다. 로그인·FCM/APNs·Gmail의 외부/국외 처리는 별개다.

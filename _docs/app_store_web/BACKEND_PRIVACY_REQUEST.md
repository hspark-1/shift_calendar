## 신규 구현 요청이 아닌 항목 — Google/Naver 해제

Flutter `AuthRepositoryImpl.deleteAccount()`에서 Google 연동 계정은 SDK disconnect를 호출하고 Naver는 SDK 토큰이 있으면 연결 해제 후 서버 탈퇴를 요청합니다. 서버는 Apple/Kakao를 처리합니다. Google/Naver 서버 revoke 신규 구현을 일괄 요청하지 않습니다.

대신 앱에서 SDK 세션이 없거나 만료된 경우, SDK 해제 성공 뒤 서버 접수 실패·네트워크 재시도, 앱 접근 불가 수동 탈퇴에서 provider 처리 경계가 어떻게 되는지 FE와 확인해 주세요. 필요 시 별도 설계를 제안하며 이미 모두 해제되었다고 단정하지 않습니다.
